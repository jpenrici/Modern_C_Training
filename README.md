# Modern C Training

Training C23 with practical examples.

This repository contains small C programs organized by topic to help learn modern C programming.

## Objectives

- Learn modern C concepts
- Practice core language features
- Explore advanced topics
- Improve coding skills

## Topics

HelloWorld, Pointers, Strings, Structs, Files, Variadic, OOP, Tic-Tac-Toe

## Build

```bash
gcc -std=c23 main.c -o app
./app
```
